A single-line cat joke for the make.fun bounty
[The One-Line Cat Joke That Lands](https://make.fun/c/u-aldy998-the-one-line-cat-joke-that-lands-a7b18262).
The program writes one joke — 63 characters, setup and punchline in a
single line — to `/output/entry.txt`:

> My cat filed a noise complaint at 3 a.m. — against the silence.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. Deterministic: every run writes the same
bytes to `/output/entry.txt`.
